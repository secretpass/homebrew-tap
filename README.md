# Secretpass Tap

## How do I install these formulae?

`brew install secretpass/tap/<formula>`

Or `brew tap secretpass/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "secretpass/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
